Screenshot Shortlist
====================

Purpose
-------
This note fixes the small curated screenshot set that may be used later in
the dissertation or paper-support pack.

Why a Shortlist Is Needed
-------------------------
Screenshots should support explanation, not create clutter.

Only implementation-relevant and evidence-relevant screenshots should be kept.
Do not capture full files, random desktop views, or oversized terminal dumps.

Capture Rules
-------------
1. Capture only the important code block or terminal result.
2. Keep the screenshot tightly cropped.
3. Make function names or decision logic clearly visible.
4. Do not include unrelated editor tabs or desktop clutter.
5. Prefer readable zoom over large full-page screenshots.
6. Use consistent naming.
